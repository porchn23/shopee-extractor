# Shopee Product Extractor (ส่วนตัว)

Chrome extension เล็กๆ อ่านข้อมูลสินค้าจาก **หน้าเว็บ Shopee ที่คุณเปิดอยู่ในแท็บปัจจุบันเท่านั้น**
ไม่ได้เชื่อมต่อเซิร์ฟเวอร์ไหน ไม่ใช้ Shopee API ไม่ผิดเงื่อนไขการใช้งาน เพราะทำงานเหมือนคุณอ่านหน้าจอเอง
แค่ให้โค้ดอ่านแทนแล้วจัดรูปแบบให้

## วิธีติดตั้ง

1. เปิด Chrome ไปที่ `chrome://extensions/`
2. เปิดสวิตช์ **Developer mode** (มุมขวาบน)
3. กด **Load unpacked**
4. เลือกโฟลเดอร์นี้ (โฟลเดอร์ที่มีไฟล์ manifest.json)
5. จะเห็นไอคอน "Shopee Extractor" ขึ้นในแถบเครื่องมือ Chrome

## วิธีตั้งค่า Google Sheet (ทำครั้งเดียว)

1. เปิด Google Sheet ใหม่ (หรือใช้ชีตเดิมที่มีอยู่)
2. เมนู **Extensions > Apps Script**
3. ลบโค้ดเดิมทั้งหมด แล้วเปิดไฟล์ `google-apps-script.gs` ที่แนบมา copy ทั้งหมดไปวางแทน
4. กด **Deploy > New deployment** → เลือกประเภท **Web app**
   - Execute as: **Me**
   - Who has access: **Anyone**
5. กด **Deploy** จะได้ URL ขึ้นต้นด้วย `https://script.google.com/macros/s/.../exec` — **copy URL นี้ไว้**
6. เปิด extension → ที่ช่อง "ตั้งค่า Google Sheet" ด้านบนสุด → วาง URL ที่ copy มา → กด **บันทึก URL** (ทำแค่ครั้งเดียว extension จะจำไว้)

จากนี้ทุกครั้งที่กด "ส่งไปที่ Google Sheet" ข้อมูลจะถูกเพิ่มเป็นแถวใหม่ในชีตนั้นอัตโนมัติ พร้อมรูปสินค้าที่แสดงในเซลล์ (ผ่านสูตร `=IMAGE()`)

## วิธีใช้

### หน้าสินค้าเดี่ยว (ดูรายละเอียดลึก 1 ตัว)
1. เปิดหน้าสินค้า Shopee ที่ต้องการ (shopee.co.th)
2. กดไอคอน extension
3. กดปุ่ม "อ่านข้อมูลสินค้าจากหน้านี้"
4. ดูผลลัพธ์ที่ขึ้นมา (ชื่อ ราคา ยอดขาย ดาว รีวิว)
5. กด "คัดลอกเป็นข้อความ" แล้วนำไปวางในแชทกับ Claude เพื่อให้ช่วยเขียนคอนเทนต์ต่อ

### หน้าค้นหา/รายการสินค้า (ดึงหลายตัวพร้อมกัน — ฟีเจอร์ใหม่)
1. เปิดหน้าค้นหาสินค้า, หมวดหมู่, หรือ Flash Sale บน Shopee
2. **เลื่อนหน้าลงให้สินค้าที่ต้องการโหลดขึ้นมาครบก่อน** (Shopee โหลดสินค้าเพิ่มทีละส่วนตอนเลื่อน ถ้าไม่เลื่อนจะอ่านได้แค่สินค้าที่เห็นตอนแรก)
3. กดไอคอน extension → กดปุ่ม "อ่านสินค้าทั้งหมดในหน้านี้"
4. จะเห็นรายการสินค้าที่พบทั้งหมด (ชื่อ + ราคา + ยอดขาย)
5. กด "คัดลอกเป็นตาราง CSV" แล้ววางลงใน Excel หรือแชทกับ Claude ได้เลย — วางได้ทีเดียวหลายสิบสินค้า

**ข้อจำกัดของฟีเจอร์นี้ที่ต้องรู้ก่อน:**
- หน้ารายการสินค้าของ Shopee **มักไม่แสดงดาว/จำนวนรีวิวในการ์ดสินค้า** (มีแค่ในหน้าสินค้าเดี่ยว) ดังนั้นฟีเจอร์นี้จะให้แค่ ชื่อ/ราคา/ยอดขาย — ถ้าต้องการดาว/รีวิวของตัวไหน ต้องเปิดหน้าสินค้านั้นแล้วใช้ปุ่ม "หน้าสินค้าเดี่ยว" เพิ่ม
- ถ้า Shopee ไม่มี JSON-LD แบบ ItemList ในหน้านั้น ระบบจะ fallback ไปแกะจากข้อความในการ์ด ซึ่งความแม่นยำขึ้นอยู่กับโครงสร้างหน้าที่เปลี่ยนได้ตลอด — ยังไม่ได้ทดสอบกับเว็บจริง ต้องลองแล้วปรับ

## วิธีดึงรายละเอียดสินค้า + รีวิว (ฟีเจอร์ใหม่ — ต้องตั้งค่าครั้งแรกก่อน)

รายละเอียดสินค้า (หลังปุ่ม "ดูเพิ่มเติม") และรีวิวผู้ซื้อ ไม่มีรูปแบบตายตัวที่เดา selector ล่วงหน้าได้แม่นยำ
จึงต้องให้คุณ **"ชี้เป้า" ครั้งแรกครั้งเดียว** ระบบจะจำตำแหน่งไว้ใช้กับสินค้าตัวอื่นต่อไปได้เลย (ตราบใดที่ Shopee ไม่เปลี่ยนโครงสร้างหน้าใหม่)

**ขั้นตอน:**
1. เปิดหน้าสินค้าใดก็ได้ 1 หน้า
2. เลื่อนลงไปดูส่วน "รายละเอียดสินค้า" — กดปุ่ม "ดูเพิ่มเติม" ให้ข้อความเต็มโชว์ก่อน
3. เลื่อนต่อไปที่ส่วน "รีวิวสินค้า" — กด "ดูเพิ่มเติม" หรือเลื่อนโหลดรีวิวให้ได้มากที่สุดเท่าที่ต้องการ (ยิ่งเลื่อนเยอะ ยิ่งดึงได้เยอะ)
4. เปิด extension → กด **"เลือกส่วนรายละเอียดสินค้า"** → เมาส์จะไฮไลต์ตอนชี้ไปตามหน้าเว็บ → **คลิกที่กล่องข้อความรายละเอียด** 1 ครั้ง (popup จะปิดตัวเอง เป็นเรื่องปกติ)
5. เปิด extension ใหม่ → กด **"เลือกส่วนรีวิว"** → **คลิกที่ข้อความรีวิวอันหนึ่ง** (อันไหนก็ได้ 1 อัน) ระบบจะหาอันที่คล้ายกันทั้งหมดในหน้าให้อัตโนมัติ
6. เปิด extension อีกครั้ง จะเห็นสถานะ "✅ ตั้งค่าส่วนรีวิวแล้ว" และ "✅ ตั้งค่าส่วนรายละเอียดแล้ว" พร้อมจำนวนรีวิวที่พบตอนเลือก
7. จากนี้กด "อ่านข้อมูลสินค้าจากหน้านี้" ตามปกติ ระบบจะดึงรายละเอียด+รีวิวมาด้วยอัตโนมัติทุกครั้ง (ไม่ต้องเลือกซ้ำ เว้นแต่ Shopee เปลี่ยนหน้าเว็บใหม่แล้วจับไม่ได้อีก ค่อยเลือกใหม่)

**ข้อจำกัดสำคัญ:** ดึงได้เฉพาะรีวิวที่ **โหลดขึ้นมาบนจอแล้วเท่านั้น** ตอนที่กด "อ่านข้อมูลสินค้า" — ถ้าอยากได้เยอะ ต้องเลื่อนหน้า/กดโหลดเพิ่มให้รีวิวขึ้นมาก่อนทุกครั้ง ไม่มีทางดึงรีวิวที่ยังไม่โหลดมาได้

## ข้อจำกัดที่ต้องรู้ล่วงหน้า

- **Shopee เปลี่ยนโครงสร้างหน้าเว็บบ่อย** โค้ดนี้พยายามอ่านจาก JSON-LD (ข้อมูลโครงสร้างมาตรฐานที่เว็บฝังไว้ให้ Google อ่าน) เป็นหลักเพราะเสถียรกว่า ถ้าไม่เจอจะ fallback ไปแกะจากข้อความในหน้าแทน ซึ่งอาจไม่แม่นยำ 100%
- **ยังไม่ได้ทดสอบกับเว็บ Shopee จริง** เพราะสภาพแวดล้อมนี้เข้าถึงเว็บ shopee.co.th ไม่ได้ — ต้องลองใช้จริงแล้วดูว่า field ไหนอ่านไม่ออกบ้าง
- ถ้าอ่านไม่ออกบางช่อง (ขึ้น "-") ให้เปิด DevTools (F12) ที่หน้า Shopee, คลิกขวาตรงข้อมูลที่ต้องการ (เช่น ยอดขาย) → Inspect → copy ชื่อ class ที่เห็น แล้วส่งกลับมาบอก Claude เพื่อปรับ selector ใน `extractor.js` ให้แม่นขึ้น
- ใช้ได้ทีละ 1 หน้าสินค้าต่อการกด 1 ครั้ง ถ้าต้องการหลายสินค้าต้องเปิดทีละหน้าแล้วกดทีละครั้ง (แต่เร็วกว่า Ctrl+A/Ctrl+C มาก เพราะจัดรูปแบบให้อัตโนมัติ)

## แผนต่อยอด (ถ้าอยากได้เพิ่ม)

- เพิ่มปุ่ม "ดาวน์โหลดเป็น CSV" สะสมหลายสินค้าในเซสชันเดียว
- เพิ่มการอ่านหน้ารายการสินค้า (search result) เพื่อดึงทีละหลายตัวในการกดครั้งเดียว
- บอก Claude ได้เลยถ้าอยากให้เพิ่มฟีเจอร์พวกนี้
