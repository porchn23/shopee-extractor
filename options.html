🛒 ตั้งค่าการเชื่อมต่อ Google Sheet

ทำครั้งเดียวประมาณ 5 นาที หลังจากนั้นกดส่งได้ตลอด

ขั้นตอนที่ 1 — สร้างชีต

  1. กดปุ่มเปิดชีตใหม่ แล้วตั้งชื่อไฟล์ (เช่น Shopee Extractor)

ขั้นตอนที่ 2 — วางโค้ด (ในชีตที่เพิ่งสร้าง)

  1. ในชีตนั้น กดเมนู ส่วนขยาย > Apps Script (ต้องเปิดจากชีตนี้เท่านั้น ห้ามสร้างสคริปต์ลอยๆ)
  2. ลบโค้ดเดิมทิ้งทั้งหมด
  3. กดปุ่มคัดลอกโค้ดด้านล่าง แล้ววางทับ (Ctrl+V) จากนั้นบันทึก (Ctrl+S)

ขั้นตอนที่ 3 — Deploy แล้วเอา URL มาใส่

  1. ใน Apps Script กด ทำให้ใช้งานได้ > การทำให้ใช้งานได้ใหม่ → ประเภท เว็บแอป
  2. ตั้ง เรียกใช้ในฐานะ: ฉัน / ผู้ที่มีสิทธิ์เข้าถึง: ทุกคน → กด Deploy → อนุญาตสิทธิ์ → คัดลอก URL ที่ลงท้าย /exec
  3. เช็คว่า Deploy ถูก: เอา URL ไปเปิดในเบราว์เซอร์ ต้องเห็นข้อความ Shopee Extractor API is running
  4. ถ้าเจอจอแดงตอนอนุญาต ให้เพิ่มเมลตัวเองเป็น Test users ใน Google Cloud Console ก่อน
  5. วาง URL ด้านล่าง → บันทึก → กดทดสอบ (จะมีแถวทดสอบ 1 แถวโผล่ในชีต ลบทิ้งได้เลย)
